## 1. 代码块（多行代码）

在代码的**上一行和下一行**，各打三个反引号 ``` （键盘左上角 ESC 下面那个键）。

**更好的是**：在开头三个反引号后面**写上语言名**，会自动着色（语法高亮）：

MARKDOWN

````
```sql
SELECT * FROM users
WHERE age > 18;
```
````

MARKDOWN

````
```python
import pandas as pd
df = pd.read_csv("data.csv")
```
````

这样 SQL 是 SQL 的颜色、Python 是 Python 的颜色，一眼看清。

## 2. 行内代码（一句话里夹代码）

用**单个反引号**把代码包起来，比如：

MARKDOWN

```
用 `SELECT` 查询，用 `groupby` 分组
```

会显示成：用 `SELECT` 查询，用 `groupby` 分组。

## 给你看一篇 SQL 笔记长什么样（照这个写）

MARKDOWN

````
# SQL 窗口函数

## 概念
窗口函数是在分组内做排名、累计计算，不减少行数。

## 语法
```sql
SELECT 
  name,
  RANK() OVER (ORDER BY score DESC) AS rank
FROM students;
```

## 例子
```sql
-- 每个班级成绩前三名
SELECT * FROM (
  SELECT *, ROW_NUMBER() OVER (PARTITION BY class ORDER BY score DESC) AS rn
  FROM students
) t WHERE rn <= 3;
```

## 易错点
- `RANK` 有并列会跳号，`DENSE_RANK` 不跳号，`ROW_NUMBER` 不并列。
````
