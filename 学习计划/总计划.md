# 🎯 毕业前总计划（2026.11 → 2027.6）

## 总目标（三条线）
- **主线·求稳定**：青海省考 + 国家电网二批
- **兜底·先挣钱**：技术就业（地点单位不挑，海投）
- **贯穿·必完成**：毕业设计 = PySpark 信贷风控项目（与求职项目同一个）

## 📅 每日时间表（11 小时）
| 时段 | 内容 | 目标 |
| --- | --- | --- |
| 上午 4h | 行测 3h + 申论 1h | 省考 |
| 下午 4h | 计算机专业（补计网/机组/数据库） | 电网二批 |
| 晚上 3h | 技术（SQL → Python/Pandas → 项目） | 就业兜底 |

## 🗓️ 月度作战图
| 月份 | 备考（主线） | 技术（晚上） | 求职 + 毕设 |
| --- | --- | --- | --- |
| 11月 | 补计网/机组/数据库 | 攻 SQL（前10题起步） | 找导师定毕设题；查资格审查学分 |
| 12月 | 电网一批当练手；补专业课 | 12月中 SQL 练到能过笔试 | 开题报告 |
| 1月 | 省考报名；行测+申论冲刺 | 补 Python + Pandas | 简历定稿 |
| 2月 | 省考笔试；电网二批报名 | PySpark 项目 MVP 跑通 | 春招启动，每周半天海投 |
| 3月 | 电网二批报名/笔试 | 项目做深、能讲清 | 春招海投+面试；毕设中期 |
| 4月 | 电网二批笔试；省考成绩 | 项目脱稿讲透+刷面试题 | 春招面试 |
| 5月 | 结果落地 | 查漏补缺 | 毕设论文+查重 |
| 6月 | 定去向 | — | 毕设答辩+毕业+签约 |

## ✅ 里程碑（到点验收）
- [ ] 12月中：SQL 中等题独立解对
- [ ] 1月中：能用 Pandas 独立清洗一份数据
- [ ] 2月底：PySpark 项目跑通 + 能讲清
- [ ] 2–4月：投出 100+ 份简历，参加笔试面试
- [ ] 6月：至少 1 个 offer 或 1 个编制上岸

> [!warning] 四条铁律
> 1. 晚上 3 小时不水过去（它是兜底的命根子）
> 2. 顺序别乱：SQL → Python/Pandas → 项目，别横跳
> 3. 项目先跑通、再讲透，别卡在"先搞懂原理"
> 4. 春招和备考同步进行，别等成绩出来才找工作
